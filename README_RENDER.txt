ONE MINUTE EMOTION GAME - RENDER VERSION

This project is prepared for deployment on Render.

Important: Render cannot be deployed directly from this ZIP. First upload the extracted project to a GitHub repository.

Steps:
1. Create a GitHub account if needed.
2. Create a new repository, for example: one-minute-emotion-game
3. Upload all files from this extracted folder to the repository.
4. Log in to Render.
5. Click New -> Blueprint (or New -> Web Service).
6. Connect your GitHub repository.
7. If using Blueprint, Render will read render.yaml automatically.
8. Deploy the service.
9. Render will give you a public HTTPS address. Open that address on any phone or computer.

No shared Wi-Fi is needed after deployment.

Notes:
- The first start may take longer because the Whisper model is downloaded and loaded.
- The service must remain successfully deployed for the site to work.
- This project uses local Whisper transcription and does not require an OpenAI API key.
