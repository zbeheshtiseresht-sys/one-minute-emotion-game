ONE MINUTE EMOTION GAME

1. Install requirements:
   py -m pip install -r requirements.txt

2. Put cloudflared.exe next to run.bat.

3. Double-click run.bat.

4. Copy the https://*.trycloudflare.com link shown in the tunnel window and open it on any phone. The phone and laptop do not need to use the same Wi-Fi.

Notes:
- The first run may download the local Whisper model.
- If Cloudflare quick tunnel times out, this is a network/connectivity issue rather than an error in the website code.
